# Milestone v1.0: MVP — Мобильная касса VITBON

**Status:** ✅ SHIPPED 2026-06-21
**Phases:** A–F + Phase 7 (closure)
**Total Plans:** 7 (one per phase)
**Total Requirements:** 52/52 satisfied

## Overview

Initial MVP release of VITBON Мобильная касса — an Android 6.0+ POS application for retail cashier operations under 54-ФЗ compliance. Ships full fiscal operations (sales, returns, corrections, shifts, X/Z reports), integration with MSPOS-K and Нева 01Ф fiscal registrars, two-way cloud sync, role-based authentication with licensing enforcement, and optional modules for Честный ЗНАК and ЕГАИС.

**Compliance:** 54-ФЗ, ФФД 1.05 / 1.2, Честный ЗНАК, ЕГАИС (runtime-gated)

## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**

- Decision: Kotlin as primary language (Rationale: Existing codebase on Kotlin; good Android ecosystem) → ✓ Good
- Decision: Room for local DB (Rationale: Reliability, offline-first, reactivity) → ✓ Good
- Decision: MSPOS-K and Нева 01Ф support (Rationale: Most common KKT in RU market) → ✓ Good
- Decision: FFD 1.05 and 1.2 (Rationale: 54-ФЗ compliance) → ✓ Good
- Decision: Cloud sync via REST API (Rationale: Standard approach, simple integration) → ✓ Good
- Decision: Optional modules for marking/EGAIS (Rationale: Not all clients need them) → ✓ Good
- Decision: SQLCipher 4.5.4 + Android Keystore (Rationale: Compliance with data-at-rest encryption) → ✓ Good
- Decision: 7-day grace period from expiresAt (Rationale: Offline resilience for cashier operations) → ✓ Good
- Decision: Server-wins conflict resolution (Rationale: Cloud is authoritative for product catalog) → ✓ Good
