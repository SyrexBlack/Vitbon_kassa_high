## Out of Scope (Confirmed Valid for v1.0)

| Feature | Reason |
|---------|--------|
| Приложение покупателя | Не входит в ТЗ — только кассирское приложение |
| Интеграция с эквайрингом | Отдельная система — платёжные терминалы |
| Desktop-версия | Только Android (мобильные устройства) |
| Windows/macOS/Linux | Не предусмотрены ТЗ |
| Полноценная CRM/ERP | Только товароучёт для кассы |
| Офлайн для маркировки | Требует онлайн-валидации |
| Офлайн для ЕГАИС | Требует онлайн-валидации через УТМ |
| Ручной ввод без ККТ | Все операции через фискальный регистратор |
| ФФД 1.0 | Не поддерживается (только 1.05 и 1.2) |
| Root/jailbreak bypass | Безопасность — блокировка или предупреждение |
